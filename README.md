# SymbioLoop — AI Powered Rubber Waste Resource Exchange

A frontend-only BE project prototype for the rubber industry.

## Features

- Login and registration
- Industry dashboard
- Rubber waste entry
- AI waste detection prototype
- AI compatibility matching
- Explainable match score
- SymbioAI assistant
- AI demand forecast
- AI cost and route optimization
- Resource exchange tracking
- Sustainability dashboard
- Responsive UI

## Run

Requirements:
- Node.js 18+ (Node 20 LTS recommended)

Commands:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally:
http://localhost:5173

## Important

This version is a working frontend prototype. The AI functions use demo/mock results so the UI can be demonstrated without a backend or API key.

For the final BE project, connect:
React -> FastAPI -> Python AI/ML -> MySQL

Suggested real AI modules:
1. Rubber image/material classification
2. Semantic material matching
3. Compatibility scoring
4. Partner ranking
5. Demand forecasting
6. Cost/route optimization
7. Explainable recommendations
8. LLM/RAG assistant
